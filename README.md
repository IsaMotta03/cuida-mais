# Cuida+

Este projeto é um trabalho acadêmico desenvolvido como uma aplicação web para auxiliar o acompanhamento de pessoas idosas, famílias e cuidadores em relação a consultas, medicamentos, histórico de acompanhamento e organização do cuidado diário. O sistema foi pensado para centralizar informações importantes em uma interface simples, prática e responsiva.

## Sobre

O projeto Cuida+ foi criado para resolver a dificuldade de organizar e acompanhar o cuidado de pessoas idosas de forma centralizada. Muitas famílias e cuidadores precisam controlar informações como medicamentos, consultas, observações do dia a dia e dados de contato de profissionais responsáveis, e isso frequentemente fica espalhado em agendas, cadernos ou mensagens.

O sistema foi pensado para ser utilizado por:
- cuidadores;
- familiares responsáveis por idosos;
- administradores.

Ele foi criado com o objetivo de facilitar a rotina de cuidado, reduzir esquecimentos e tornar a gestão de informações de saúde mais clara e acessível.

> Este projeto foi desenvolvido como trabalho acadêmico, com foco na criação de uma solução prática de organização e acompanhamento.

## Funcionalidades

- Cadastro e autenticação de usuário na interface de login e cadastro;
- Cadastro de pessoas relacionadas ao cuidado, como idosos, cuidadores e familiares;
- Visualização geral do painel com indicadores e informações resumidas;
- Organização de medicamentos com listagem e controle de itens;
- Agendamento e acompanhamento de consultas;
- Registro de acompanhamentos e observações do cotidiano;
- Armazenamento local dos dados no navegador por meio de `localStorage`;
- Interface responsiva para uso em diferentes tamanhos de tela.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage do navegador
- Layout responsivo e navegação por múltiplas páginas estáticas

## Instalação

1. Clone este repositório para sua máquina local;
2. Abra a pasta do projeto;
3. Para visualizar a página, basta abrir o arquivo login.html em um navegador.
